## A focused recording, then an explicit handoff

Open the launcher with **⌘⇧Space** and choose **Video**. Show the starting state, repeat the action, and explain the expected and actual result. Stop after one reproduction. Verify the saved video has your voice before recording a longer session.

When signed-in processing completes, review `transcript.md` and `summary.md` in the capture folder. Those are text outputs from recording audio. They do not mean an assistant has inspected the screen. Supply a screenshot of the important state or attach a video when the receiving assistant supports it.

## What the current app does not infer

The released workflow does not automatically extract a frame-by-frame visual timeline, produce `context.md`, or expose a local walkthrough MCP server. An agent reading only a transcript knows the words, not the visual evidence. The hosted MCP server retrieves supported account text; it does not open video files on your Mac.

For a bug report, add a concrete request such as “Inspect the disabled Export button after I switch workspaces.” Ask the agent to identify which sources it opened. This keeps its interpretation grounded in the evidence it actually received.

## Local files and cloud audio

Capture saves local media. With the required recognition permission and available models, on-device captions can show preliminary text. Signed-in audio processing produces a cloud transcript and brief. Review sensitive content before separately sharing it with another AI service.
