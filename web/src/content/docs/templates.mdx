When a recording finishes processing, Eavesy writes a brief on top of the
transcript. Briefs need an account.

## What's in a brief

- a title and a short summary,
- decisions that were made,
- action items, with owners and due dates when they were mentioned, and
- open questions.

It's plain Markdown, so you can paste it straight into an agent. It's also
saved as `summary.md` in the recording's folder on a signed-in Mac.

## Use a built-in format

Open a completed recording on the web, pick a format above the brief, and
choose **Regenerate**:

- **Standard brief** for decisions, actions and open questions,
- **Meeting notes** for owners, due dates, blockers and follow-up,
- **Coding session** for goals, files, commands, attempts and next steps,
- **Research session** for questions, findings, sources and uncertainty, or
- **Customer conversation** for goals, pain points, objections and
  commitments.

Regenerating never changes the transcript. If you edited the brief, Eavesy
asks before replacing it.

## Make your own template

Go to **Settings → Brief templates** in the web app. Give the template a name
and describe the sections and emphasis you want. You don't need to include the
transcript. Eavesy adds it when you regenerate.

For example, a sales template could ask for the prospect, pain points,
objections, and the next step with an owner. A coding template could ask for
file paths, decisions, TODOs and test results.

## Edit the brief

Choose **Edit** to change the wording yourself. **Restore generated** brings
back the last generated version.

On a Mac, you can also edit `summary.md` in any editor. Eavesy never overwrites
a file you've changed.
