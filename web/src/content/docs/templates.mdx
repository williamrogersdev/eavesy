A meeting, customer conversation, research session, and coding walkthrough each
need different notes. Eavesy lets you reshape a completed brief without changing
the source transcript.

## Use a built-in format

Open a completed recording and pick a format from the menu above the brief, then choose **Regenerate**:

- **Standard brief** for balanced decisions, actions, and open questions,
- **Meeting notes** for owners, due dates, blockers, and follow-up,
- **Coding session** for goals, files, commands, attempts, evidence, and next steps,
- **Research session** for questions, findings, sources mentioned, and uncertainty, or
- **Customer conversation** for goals, pain points, objections, commitments, and follow-up.

Select **Regenerate** to create the new brief. Regeneration keeps the transcript
intact. If you edited the current brief, Eavesy asks you to confirm before
replacing it.

## Create your own

Go to **Settings → Brief templates**. Give the template a clear name and write
instructions describing the sections, emphasis, and constraints you want. You
do not need to paste the transcript into the instructions; Eavesy adds it when
you regenerate a recording.

For example, a sales template could request:

- Prospect and company
- Pain points raised
- Objections
- Next step and owner

A coding-agent template could emphasize file paths, decisions, explicit TODOs,
test evidence, and the exact next step.

## Edit the Markdown directly

Choose **Edit** when you want precise wording instead of another AI
pass. Saving creates an editable version while preserving the generated data.
Use **Restore generated** to discard the edit and return to the last
generated result.
