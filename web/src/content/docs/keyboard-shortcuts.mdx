## Global shortcuts

These work from any app.

| Action | Default |
| --- | --- |
| Open or hide Eavesy | `⌘⇧Space` |
| Talk | `⌘⇧D` |

Change either one in the Mac app under **Settings → Shortcuts**. **Restore
default shortcuts** puts both back.

Talk can also be set to the `fn` key, which needs the Input Monitoring
permission.

There are no other global shortcuts. Meeting, Video and Screenshot start from
the launcher.

## Tap or hold Talk

- **Tap** to start, and tap again to stop.
- **Hold** for more than 350 ms for push-to-talk. Letting go stops it.

**Start or Stop Recording** in the menu bar does the same as the Talk shortcut.

## Inside the launcher

| Key | Action |
| --- | --- |
| `⌘V` | Save what's on your clipboard |
| `/` | Search your captures |
| `N` | Write a note |
| `⌘,` | Open settings |
| `Esc` | Close the launcher, or go back |

The web app doesn't have global shortcuts.
