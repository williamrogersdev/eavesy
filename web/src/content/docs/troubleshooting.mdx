Most problems come down to a macOS permission. Open **Settings → Permissions**
in the Mac app to see which ones are on, or choose **Run setup again**.

## A meeting only has my side

Hearing the other side of a call needs the **Screen Recording** permission.

1. Allow Eavesy in **System Settings → Privacy &amp; Security → Screen &amp;
   System Audio Recording**.
2. If the permissions list offers to reopen Eavesy, let it.
3. Check that the call plays through an output you can hear. Eavesy records
   what your Mac plays, so a muted or different device won't be heard.

## My voice isn't recorded

Allow **Microphone** in **System Settings → Privacy &amp; Security →
Microphone**, then start a new recording.

## Talk doesn't paste

- Pasting needs the **Accessibility** permission.
- Your cursor needs to be in a text field when you stop.
- On-device text needs **Speech Recognition**. Without it, Talk waits for the
  cloud transcript, which needs you to be signed in.

## fn opens the emoji picker

In **System Settings → Keyboard**, set "Press 🌐 key to" to **Do Nothing**.
Using `fn` as the Talk key also needs **Input Monitoring**.

## There are no live captions

Captions need **Speech Recognition**. Check that **Settings → Live captions** is
on in the Mac app.

## There's no transcript or brief

Cloud transcripts and briefs need you to be signed in.

- Check your internet connection. Audio has to upload before it can be
  transcribed.
- Long recordings arrive in batches while they upload.
- Very quiet audio can come back empty. Move closer to the microphone, or turn
  up the call.
- If you hit a [fair-use limit](/docs/fair-use-limits), try again after
  midnight UTC.

## A browser recording didn't finish uploading

Keep the tab open and choose **Try again** once you're back online. The upload
picks up where it stopped. You can also **Download** the recording to keep a
copy. If the tab closed, the parts that already uploaded still become a
transcript.

## macOS warns about the app on first launch

Eavesy is notarized by Apple, so this is rare. If it happens, open **System
Settings → Privacy &amp; Security**, scroll down, and choose **Open Anyway**.

## Still stuck?

[Open an issue on GitHub](https://github.com/williamrogersdev/eavesy/issues)
or email <a href="mailto:support@eavesy.com">support@eavesy.com</a>. Include
your macOS version and what you were doing.
