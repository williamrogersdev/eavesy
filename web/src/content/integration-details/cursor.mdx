## Speak into the input you are using

Place your cursor in the intended Cursor text input and use Eavesy Talk. Stop after a short test sentence, then check where the words landed. Accessibility permission allows automatic pasting; the selected target field still matters. Inspect technical identifiers before submitting a prompt.

You can also copy a completed recording brief or a note into Cursor manually. Add a focused instruction explaining what the agent should do with that context rather than pasting a large transcript without a question.

## Add the screenshot when appearance matters

Attach the image through the input supported by your installed Cursor client. If the agent runs locally, it may also inspect a permitted image path. Do not assume a remote agent can read local files. Ask it to describe the actual visible evidence before diagnosing a layout issue.

## Optional hosted MCP connection

Cursor supports remote MCP connections. Add Eavesy's hosted URL through the MCP settings of your installed client, or use this configuration with a client supporting HTTP OAuth:

```json
{
  "mcpServers": {
    "eavesy": { "url": "https://mcp.eavesy.com" }
  }
}
```

Authenticate with Eavesy when prompted and approve the connection. Confirm the tools are available with a narrow recording lookup. This covers supported synced account recordings and dictations, not your Mac's local screenshot library. See [Cursor's MCP documentation](https://cursor.com/docs/mcp) for current configuration locations and client behavior.

## Keep the handoff small

For a bug, give the starting state, the triggering action, expected behavior, observed behavior, and one relevant screenshot. Eavesy does not need to control Cursor or send your whole library to make that context useful.
